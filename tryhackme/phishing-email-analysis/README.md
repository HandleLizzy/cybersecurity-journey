# Phishing Email Analysis and Investigation

## Project Overview

This project documents my practical learning and investigation of phishing emails through hands-on cybersecurity exercises and labs.

The objective is to develop practical skills in phishing detection, email header analysis, URL investigation, identification of Indicators of Compromise (IOCs), and phishing prevention.

## Learning Platform
- TryHackMe

## Areas of Investigation
- Phishing email identification
- Email header analysis
- Sender authentication (SPF, DKIM and DMARC)
- Malicious URL investigation
- Phishing analysis tools
- Indicators of Compromise (IOCs)
- Security recommendations and prevention

## Project Status
In Progress

## Disclaimer
This repository is intended for educational and defensive cybersecurity purposes. All investigations are conducted in authorised learning environments.
