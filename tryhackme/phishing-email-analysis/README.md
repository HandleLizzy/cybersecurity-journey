# Phishing Email Analysis

## Project Overview

A practical phishing email investigation based on an ADT-themed promotional email.

The project demonstrates a structured approach to email analysis, IOC investigation, threat intelligence and sandbox behaviour analysis.

## Investigation Objectives

- Analyse email headers and authentication results.
- Identify domains, IP addresses and URLs.
- Investigate indicators using VirusTotal.
- Review sandbox behaviour.
- Document findings and provide an evidence-based assessment.

## Tools Used

- Thunderbird
- VirusTotal
- TryHackMe

## Skills Demonstrated

- Phishing email analysis
- Email authentication (SPF, DKIM and DMARC)
- IOC investigation
- Threat intelligence
- Sandbox analysis
- MITRE ATT&CK awareness
- Investigation documentation

## Investigation Outcome

**Assessment: Inconclusive**

The available evidence was insufficient to classify the email as either malicious or legitimate.
