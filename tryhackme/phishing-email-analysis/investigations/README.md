# Phishing Investigations

This directory contains practical phishing email investigations conducted as part of my cybersecurity learning journey.

## Investigation Objectives

- Identify suspicious email characteristics.
- Examine email headers and sender information.
- Investigate suspicious URLs and domains.
- Identify Indicators of Compromise (IOCs).
- Assess phishing techniques.
- Document findings and recommend defensive actions.

## Investigation Reports

Practical investigation reports will be added as I progress through the TryHackMe Phishing Analysis module.

## Methodology

Each investigation will document:

1. Incident overview
2. Initial observations
3. Technical analysis
4. Indicators of Compromise
5. Investigation findings
6. Recommended mitigation measures
